예약 문구 입력 — C# 재작성 버전 (Windows 10/11 x64)

이 패키지는 소스 기반입니다. 미리 빌드한 EXE, 설치 프로그램, 외부 DLL은
포함하지 않습니다. 이전 버전의 EXE를 복구하거나 함께 사용하지 마세요.

실행
1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. Start.cmd를 실행합니다.
3. Build.cmd가 Windows에 설치된 Microsoft .NET Framework C# 컴파일러로
   App.cs와 Schedule.cs를 빌드합니다. 같은 폴더에 ScheduledText.exe가 생깁니다.
4. 빌드가 성공하면 프로그램 창이 열립니다.
컴파일러가 없거나 빌드가 차단되면 중단합니다. 다른 파일을 다운로드하지 않습니다.
Start.cmd는 매번 소스로 빌드하며, 실패 시 기존 EXE를 실행하지 않습니다.
컴파일러, 바이러스 검사 결과 또는 파일이 차단되는 경우 그 상태를 유지하세요.
보안 기능 해제, 예외 등록, 실행 정책 변경, 관리자 실행은 요구하지 않습니다.

사용
- 메모장 입력칸 위에 마우스를 놓고 F8을 눌러 좌표와 대상 창을 저장합니다.
- F8이 등록되지 않으면 '위치 지정' 버튼을 누르고 3초 안에 이동합니다.
- 입력할 문구를 적습니다. 처음에는 무해한 짧은 문구를 사용하세요.
- '지금부터 대기'는 설정한 분·초 뒤 한 번 입력합니다. 기본 5분입니다.
- '날짜·시간 지정'은 지정한 PC 현지 날짜·시간에 한 번 입력합니다.
  해당 날짜·시간은 실행 기준 설정값이며 현재 시각을 표시하는 시계는 없습니다.
- '1분 후 시작'을 체크하면 1분 뒤 첫 입력, 이후 설정한 분·초 간격으로 반복합니다.
  5분 설정이면 시작 후 1분 → 6분 → 11분 → 16분…입니다.
  반복 모드에서는 날짜·시간 지정을 사용하지 않습니다.
- '예약 시작'을 누르면 즉시 예약 시작됨, 경과 시간, 다음 입력까지 남은 시간,
  입력 신호 전송 횟수가 표시됩니다.
- 저장 좌표를 왼쪽 클릭하고 0.3초 뒤 문구를 입력합니다. 기존 글을 지우지 않습니다.
- '입력 후 Enter'는 기본 해제입니다. 체크하면 매번 마지막에 Enter를 누릅니다.
  문구 속 줄바꿈도 Enter입니다. Enter로 전송되는 앱에서는 한 줄로 작성하세요.
- Esc 또는 취소 버튼으로 중단합니다. 종료하면 예약은 유지되지 않습니다.
  이미 클릭·입력·전송된 내용은 되돌리지 않습니다.

보완한 중단 조건
- 지정 좌표의 창이 달라지거나 대상 창이 닫히거나 숨겨지면 중단합니다.
- 클릭 후 입력 중 다른 창으로 전환하면 중단합니다.
- 2초를 넘는 실행 지연이나 절전 복귀를 감지하면 중단합니다.
- 입력이 다음 반복 시각까지 이어지면 중단합니다. 밀린 입력을 몰아서 실행하지 않습니다.
- 입력 실패 시 중단합니다. 관리자 권한 대상 앱 등에 대한 입력은 차단될 수 있습니다.
창의 위치·크기·모니터 배율을 유지하고 PC 잠금·절전을 해제해 두세요.
같은 창 안에서 입력칸이 이동한 경우까지 판별할 수는 없습니다.
전송 횟수는 Windows에 입력 신호를 보낸 횟수이며 대상 앱의 처리 성공 보장은 아닙니다.

점검 범위
컴파일 검증과 예약 계산/입력 구조 16개 검증 항목 통과.
실제 Windows GUI와 Defender 검사, 코드 서명 검증은 수행하지 못했습니다.
이 패키지도 안전 인증을 받은 배포물이 아닙니다. 탐지 경고가 나면 중단하고
탐지 이름과 파일 경로를 확인하세요. 보안 예외 등록을 요구하지 않습니다.
