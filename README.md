# 예약 클릭 (Windows 10/11 x64)

`dist/Setup.exe`를 실행해 설치한 뒤 바탕화면의 **예약 클릭**을 실행하세요. 별도 Python/.NET 설치가 필요 없습니다. 현재 사용자 계정에 설치하며 앱 목록에서 제거할 수 있습니다.

1. PC의 현지 날짜와 시·분·초를 지정합니다(24시간 표시).
2. 추가 클릭 횟수(0~20)와 간격(10~1000ms)을 입력합니다. 기본값은 최초 1회 + 추가 3회, 50ms 간격입니다.
3. **예약 시작**을 누르고 원하는 지점에 마우스를 놓으세요. 예약 시각에 그 위치를 저장하여 같은 좌표를 클릭합니다.
4. 대기 중이나 연속 클릭 중 **Esc**로 취소할 수 있습니다.

Windows 입력 전송 성공이 대상 앱의 처리 성공을 뜻하지는 않습니다. 따라서 추가 클릭은 성공 여부와 관계없이 실행합니다. 결제·제출 등 중복 실행이 위험한 동작에는 추가 클릭을 0으로 설정하세요. 클릭 후 대상 화면이 바뀌면 같은 좌표가 다른 버튼을 가리킬 수 있습니다.

PC를 켜고 잠금과 절전을 해제하세요. 앱 종료 후에는 예약이 유지되지 않습니다. 예약을 2초 이상 지나친 경우 뒤늦게 클릭하지 않습니다. 초 단위 입력을 지원하지만 Windows 스케줄링과 시스템 부하로 실제 실행 시각에는 오차가 생길 수 있습니다. 관리자 권한 앱이나 보안 데스크톱에서는 입력이 차단될 수 있습니다. 시스템 시계 기준이며 서버 시각 동기화 기능은 없습니다. 배포 파일은 코드 서명되지 않아 SmartScreen 경고가 표시될 수 있습니다.

## 빌드

Linux: MinGW-w64 GCC, NSIS를 설치하고 `bash scripts/build.sh`를 실행합니다.
Windows: MSYS2 UCRT64/MinGW-w64 GCC와 NSIS를 설치하고 해당 셸에서 `bash scripts/build.sh`를 실행합니다. 필요 시 `CC=gcc MAKENSIS='/c/Program Files (x86)/NSIS/makensis.exe' bash scripts/build.sh`로 경로를 지정합니다.

이 클라우드에서는 Debian 패키지를 `/workspace/toolchain`에 추출한 도구를 사용합니다. `scripts/setup-cloud.sh`로 설치한 뒤 `bash scripts/build.sh`를 실행하세요.

## Windows에서 최종 검증

실제 Windows에서는 아직 실행 검증하지 않았습니다. 메모장 같은 무해한 창에서 몇 초 뒤 예약, 취소, 추가 클릭 0/3회, 과거 시각 거부를 확인하세요. 다중 모니터·화면 배율 환경에서도 원하는 지점이 클릭되는지 확인하세요. `Setup.exe` 설치 → 바탕화면 실행 → 앱 목록에서 제거 과정도 확인하세요.
